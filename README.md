# Mezana Unified Platform (Yangi Tizim)

Ushbu repozitoriyada faqatgina **Mezana yangi yagona boshqaruv va moliya tizimi** kodlari joylashgan:

- **`apps/finance/`** ? Yagona Boshqaruv, Moliya, Talabalar, Davomat, Oshxona, Masjid va Smart Kampus Web interfeysi (`App.tsx`, `UnifiedModules.tsx`, `CampusSmartDashboard.tsx`, `AiAssistantModal.tsx`).
- **`apps/finance-bff/`** ? Yagona Backend BFF serveri (`server.mjs`), ZKTeco turniket/oshxona/masjid integratsiyasi (`campusSmartService.mjs`) va Kamera Yuzni Tanish (`gate_entry_detector.py`, `face_recognizer.py`).
- **`apps/telegram-bot/`** ? Moliya, Xarajatlar, Xarajatga Talabnomalar (`sandboxFlow.ts`) va Kech qoluvchilarni tasdiqlash (`late/flow.ts`) Telegram boti.
- **`apps/ai-assistant/`** ? AI Moliyaviy Yordamchi va Chek OCR moduli.
